程式碼重點

核心只有一個迴圈：每個畫面偵測一次

function detectPose() {

  const result = poseLandmarker.detectForVideo(video, performance.now());

  if (result.landmarks.length > 0) {

    const landmarks = result.landmarks[0];  // 33 個關鍵點

    drawingUtils.drawConnectors(landmarks, POSE_CONNECTIONS);  // 畫連線

    drawingUtils.drawLandmarks(landmarks);  // 畫關鍵點

  }

  requestAnimationFrame(detectPose);  // 下一個畫面再做一次

}

detectForVideo：把目前畫面交給模型分析

landmarks[0]：畫面中第一個人的 33 個點

requestAnimationFrame：瀏覽器每次重畫時再呼叫

簡化版；完整程式碼見 GitHub：ttweew/claude-workspace 的 index.html

這是核心程式的簡化版。detectForVideo 把目前這一格畫面交給 MediaPipe，回傳結果裡的 landmarks[0] 就是畫面中第一個人的 33 個關鍵點。接著用 MediaPipe 內建的工具畫出連線和點。最後 requestAnimationFrame 讓瀏覽器在下一次重畫時再呼叫這個函式，形成即時的迴圈。整個網頁是一個 index.html，純 HTML 加 JavaScript。
