錄製資料的格式：欄位與範例

CSV：一列一格畫面，498 欄（前 234 欄是原始資料，和以前一樣）

frame,time_ms,detected,nose_x,nose_y,nose_z,nose_vis, …
0,0,1,0.51420,0.22520,-0.33100,0.999, …

JSON：給之後的後端 AI 使用，包含裝置資訊

{ "format": "ai-sport-pose", "version": 1,
  "meta": { "videoWidth": 640, "computeMode": "GPU", … },
  "frames": [ { "t": 0, "landmarks": [[x, y, z, 可信度], …] } ] }

234 欄 = 3 欄（格數、時間、有沒有偵測到）＋ 33 點 × 4（畫面座標 x、y、z、可信度）＋ 33 點 × 3（公尺座標）。10/4 起後面再加：平滑後的點 165 欄、處理過的公尺座標 99 欄，原始資料不變。最長 5 分鐘。
