哪些點算「看得到」

export function isVisible(point) {
  return point.visibility >= 0.65   // 可信度
      && point.x >= 0 && point.x <= 1  // 在畫面內
      && point.y >= 0 && point.y <= 1
}

白話解說

AI 一定會給 33 個點

就算部位不在畫面裡，也會「猜」一個位置

每個點附帶可信度 visibility

AI 認為這個點真的看得到的機率，0～1

0.65 是實測出來的

只拍到頭時，猜出來的手腕約 0.5～0.6；真的看到的點幾乎都在 0.8 以上

所有功能共用這個判斷

畫骨架、算角度、入鏡提示、數據面板的淡色
