白話解說

GPU 優先，CPU 備援

GPU 快很多；不支援的裝置自動改用 CPU，網站照樣能用

提前暖機

第一次偵測特別慢，在首頁就先跑掉；開鏡頭後骨架約 1 秒出現

自動恢復

手機切到背景時系統可能收回 GPU，偵測到就重新建立，約 1 秒

救不回來時說清楚

提示使用者關閉鏡頭重開或重新整理，不會默默壞掉
