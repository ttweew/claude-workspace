關節角度怎麼算：向量夾角

// 三個點的夾角，例如 髖 - 膝 - 踝（簡化）
function angleAt(a, b, c) {
  const u = [a.x - b.x, a.y - b.y]   // 膝→髖
  const v = [c.x - b.x, c.y - b.y]   // 膝→踝
  const dot = u[0]*v[0] + u[1]*v[1]  // 內積
  const len = |u| * |v|              // 長度相乘
  return acos(dot / len) × 180 / π  // 換成角度
}

角度的計算其實就是高中數學的向量夾角。以膝蓋為例，從膝蓋到髖部是一個向量，從膝蓋到腳踝是另一個向量，用內積除以長度相乘得到 cos θ，再反推角度。要注意的是畫面座標是比例，640 乘 480 的畫面不是正方形，所以要先換算成像素。三個點只要有一個是猜的，就不計算。
