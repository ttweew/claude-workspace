TOOLS · 開發用的網址參數

在網址後面加上參數，就能切換測試模式

?debug

測試模式

一打開就顯示關節編號；運算標籤另外顯示下載、啟動、暖機各花幾秒

?cpu

強制使用 CPU

同一台裝置比較 GPU 和 CPU 的速度差距

?res=720　?res=1080

提高鏡頭解析度

比較不同解析度的 FPS（預設 640×480）

?model=full

改用較大的模型

鬼點更少但較慢，用手機比較後再決定是否換成預設

例：ttweew.github.io/claude-workspace/?model=full
