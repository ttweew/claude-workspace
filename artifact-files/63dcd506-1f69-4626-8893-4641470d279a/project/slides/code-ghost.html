擋掉鬼點的三道檢查

// 1. 出現要穩定
if (清楚的時間 >= 80 毫秒) shown = true
if (visibility < 0.6) shown = false

// 2. 骨架鏈：往身體方向一路檢查
for (j = PARENT[i]; j; j = PARENT[j])
  visible = visible && shown[j]

// 3. 塌縮保護（身體大小）
size = 軀幹長 + 肩寬 + 髖寬
if (size < 0.3 秒內最大值 × 0.7) 鬼骨架

白話解說

為什麼需要

鬼點的可信度常高達 0.8～0.96，上一頁的規則擋不住

出現要穩定

閃一下就消失的點不畫；出現與消失用不同門檻，不會一直閃

骨架鏈

手腕 → 手肘 → 肩膀，中間斷掉就不畫，手不會單獨飄在空中

塌縮保護

用軀幹、肩寬、髖寬：深蹲時這三個長度幾乎不變，不會誤判

上一頁的規則擋不住鬼點，因為鬼點的可信度很高。所以加了三道檢查。第一，點要穩定出現一段時間才畫。第二，骨架鏈：手腕要手肘也看得到、手肘要肩膀也看得到。第三，塌縮保護：用軀幹長加肩寬加髖寬當作身體大小，如果零點三秒內縮小超過三成就是鬼骨架。選這三個長度是因為深蹲、彎腰時它們幾乎不變，不會誤判。
