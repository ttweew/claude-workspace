# 日後改進與規劃

這份文件記錄「已經知道、但還沒做」的事情，避免只存在對話裡而遺失。
每完成一項就把狀態改成「完成」並寫上 PR 編號。

## 四、深蹲實驗功能（`?lab=squat`）

（10/14 起深蹲已經是正式的運動模式，首頁卡片按「開始深蹲」就能用，計算方式和下面相同；重播分析頁的深蹲分析仍然要加 `?lab=squat`。）

以前一般使用者看不到；網址加上 `?lab=squat` 才會出現（例如 `https://ttweew.github.io/claude-workspace/?lab=squat`），重播分析頁也一樣（`replay.html?lab=squat`）。

**怎麼算一下**：先站直（膝蓋 ≥ 160°）→ 往下蹲到膝蓋 ≤ 140° → 再站直。兩個門檻不同，角度在門檻附近抖動時才不會多算；不到 0.5 秒的不算；蹲到一半看不到人超過 1.5 秒，那一下作廢。

**深度判斷**（看每一下最低的膝蓋角度）：≤ 90° 蹲到位、90～110° 再低一點、> 110° 太淺。

**只在側面、斜側面拍時計算**，正面拍會提示「請側身對著鏡頭」。

**畫面上**：大字儀表板多一格「深蹲」次數；每完成一下，上方短暫顯示「第 3 下 · 85° 蹲到位」（綠：蹲到位、黃：再低一點、紅：太淺）。

用合成資料測試（14 項全部通過；另外把 MediaPipe 換成播放合成深蹲的假模組，從鏡頭畫面端到端測試，5 下全部正確顯示）：

| 情境 | 結果 |
|---|---|
| 拍攝角度 0°、8°、20°、28°，面向左右都測 | 5 下全對；側面時最低膝蓋角度誤差 ≤ 3.6°，斜 28° 時 ≤ 7.3° |
| 正面拍 | 0 下，99% 的時間有提示側身 |
| 雜訊加倍（3 像素） | 5 下全對 |
| 只是小幅度晃動（膝蓋 145～152°） | 0 下（不會誤算） |
| 很快（每下 1.2 秒）、很慢（每下 7.5 秒、底部停 2 秒） | 都算對 |
| 蹲到一半看不到人 2 秒 / 0.5 秒 | 那一下作廢 / 照算 |
| 一開始就蹲著 | 第一下不算（要先站直） |

**老師決定的（10/12）**：
- 深度門檻：「蹲到位」用膝蓋 90°，不用「大腿和地面平行」（約 60～70°）。只看髖、膝、踝三點的夾角，不用考慮地面；手機放歪時夾角也不變

**要和老師、組員討論的**：
- 要不要加其他判斷：例如上半身前傾太多（髖部角度）、膝蓋內夾（要正面拍才看得到，和側面拍衝突）
- 真人錄影驗證：用重播分析頁（`replay.html?lab=squat`）檢查每一下有沒有算對
